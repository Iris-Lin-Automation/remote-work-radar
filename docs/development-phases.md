# Remote Work Radar - 开发阶段与过程

## 项目概述

Remote Work Radar 是一个 AI 驱动的远程岗位情报与筛选系统，专注于解决海外远程岗位信息分散、地区限制与 JD 阅读成本高的问题。

## 技术栈

### 核心技术
- **运行环境**: Node.js 18+, Docker, Docker Compose
- **数据库**: PostgreSQL 15 + pgvector (向量存储)
- **AI 引擎**: 
  - SiliconFlow/DeepSeek (主要 LLM)
  - sentence-transformers/all-MiniLM-L6-v2 (向量嵌入)
  - BAAI/bge-reranker-base (重排序)
- **自动化**: n8n 工作流引擎
- **可视化**: HTML + Chart.js + 自定义看板
- **数据采集**: RSS/REST API + n8n 节点

### 测试策略

- **端到端测试**: 完整工作流程

### 监控指标
- **数据质量**: 采集成功率、去重率

## 风险管理

### 技术风险
- **API 限制**: 多源 API 调用限制
- **数据质量**: 不同来源数据格式差异
- **AI 可靠性**: LLM 输出稳定性

### 业务风险
- **市场竞争**: 其他类似工具竞争
- **用户需求**: 求职需求变化
- **法律合规**: 数据隐私和版权问题

### 应对策略
1. **技术方案**: 备选数据源、本地模型部署
2. **业务策略**: 差异化功能、用户反馈驱动
3. **合规措施**: 数据脱敏、权限控制
